# Лабораторная работа №2: MPI, метод Якоби 3D

## Описание
Решение трёхмерного уравнения Пуассона методом Якоби с распараллеливанием по MPI.

## Файлы
- `yacobi3d.c` — исходный код программы
- `job_bench.sh` — SLURM-скрипт для замеров времени (1, 2, 4, 8, 16 ядер)
- `job_profile.sh` — SLURM-скрипт для профилирования MPE на 16 ядрах

## Компиляция на кластере НГУ (nks-1p.sscc.ru)
```bash
module purge
module load oneapi/2022.3.1/ALL
mpicc -std=c99 -O3 -o yacobi3d yacobi3d.c -lm
